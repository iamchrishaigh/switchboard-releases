# Switchboard releases

Signed, notarised downloads of Switchboard, a Haigh Labs Mac app, and the update list it checks.

**Download:** [Switchboard.dmg](https://github.com/iamchrishaigh/switchboard-releases/releases/latest/download/Switchboard.dmg). Open it and drag Switchboard into Applications.

Once it's installed, Switchboard updates itself: it checks `appcast.xml` here and offers each new version.
Releases are made with `scripts/release.sh` in the Switchboard source repo, which is private.
